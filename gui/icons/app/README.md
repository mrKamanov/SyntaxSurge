# Иконки кнопок приложения

Набор иконок для кнопок SyntaxSurge (источник: [Lucide Icons](https://lucide.dev), единый стиль).

## Верхняя панель (title bar)

| Файл | Назначение | Состояние |
|------|------------|-----------|
| `title_tray.svg` | Свернуть в трей | — |
| `title_pin.svg` | Приклеить к краю | приклеено |
| `title_pin_off.svg` | Приклеить к краю | отклеено |
| `title_close.svg` | Закрыть | — |

## Сайдбар — главная

| Файл | Назначение |
|------|------------|
| `sidebar_send.svg` | Отправить ИИ |
| `sidebar_play.svg` | Печать ответа / Старт |
| `sidebar_pause.svg` | Пауза печати |
| `sidebar_screenshot.svg` | Скриншот |
| `sidebar_get_answer.svg` | Получить ответ |
| `sidebar_stop.svg` | Стоп (печать/помощник) |

## Сайдбар — помощник

| Файл | Назначение | Состояние |
|------|------------|-----------|
| `sidebar_volume.svg` | Звук вкл | мьют выкл |
| `sidebar_volume_mute.svg` | Мьют | мьют вкл |
| `sidebar_clear.svg` | Очистить | — |

Отправка (Помощник) использует `sidebar_send.svg`.
