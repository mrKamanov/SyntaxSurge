# SyntaxSurge Bridge — расширение для VS Code / Cursor

Расширение отправляет **позицию курсора** (строка, столбец) и **контекст строк** (текущая, выше, ниже) на локальный мост приложения SyntaxSurge (`http://127.0.0.1:8765/cursor`), в том же формате, что и userscript для Yandex.Code.

Так приложение может получать актуальные данные из редактора при печати в VS Code или Cursor и при необходимости синхронизировать позицию (логика как в браузере).

## Как установить расширение в VS Code / Cursor

Расширение нужно либо **запустить для теста** (F5), либо **установить постоянно** через файл `.vsix`.

### Вариант А: Запуск для теста (без установки)

Удобно, чтобы быстро проверить работу.

1. Открой в VS Code или Cursor **папку проекта** `SyntaxSurge` (корень репозитория).
2. Открой папку **`vscode-extension`** в боковой панели.
3. В терминале из корня проекта выполни:
   ```bash
   cd vscode-extension
   npm install
   npm run compile
   ```
4. Нажми **F5** (или меню **Run → Start Debugging**).
5. Откроется **второе окно** редактора с подписью «[Extension Development Host]» — в нём расширение уже включено. Работай в этом окне: открывай файлы, двигай курсор; данные будут уходить на мост.

Чтобы расширение перестало работать, просто закрой это второе окно.

---

### Вариант Б: Установить постоянно (через .vsix)

Так расширение будет стоять в твоём обычном VS Code/Cursor и включаться при каждом запуске.

1. Собери расширение (если ещё не делал):
   ```bash
   cd vscode-extension
   npm install
   npm run compile
   ```

2. Установи утилиту для упаковки расширений (один раз):
   ```bash
   npm install -g @vscode/vsce
   ```

3. Создай файл `.vsix` (в папке `vscode-extension`):
   ```bash
   vsce package
   ```
   Появится файл вида `syntaxsurge-bridge-0.1.0.vsix`.

4. Установи его в редактор:
   - Открой **обычное** окно VS Code или Cursor (не Extension Development Host).
   - Открой панель расширений: **Ctrl+Shift+X** (или View → Extensions).
   - Справа вверху нажми **«...»** (три точки) → **«Install from VSIX...»**.
   - Укажи файл `syntaxsurge-bridge-0.1.0.vsix` (он в папке `vscode-extension`).
   - После установки расширение появится в списке; при необходимости перезапусти редактор.

Готово: расширение установлено и будет работать при каждом запуске VS Code/Cursor.

## Использование

1. **Запусти мост** — открой GUI (`python gui_typer.py`) или запусти `python run.py`. Мост слушает порт 8765.
2. Включи расширение **SyntaxSurge Bridge** в VS Code/Cursor.
3. Открой любой файл и двигай курсор — расширение будет отправлять позицию и три строки на мост.
4. В GUI SyntaxSurge в блоке «Статус» при фокусе в редакторе будет отображаться источник «VS Code / Cursor» и позиция (строка N, столбец M).

Команда **SyntaxSurge: проверить подключение к мосту** (Command Palette) проверяет, доступен ли мост, и показывает текущую позицию.

## Формат данных

POST `http://127.0.0.1:8765/cursor` с телом JSON:

- `line`, `column` — 1-based (как в мосте и в приложении).
- `lineContent`, `lineAbove`, `lineBelow` — текст текущей строки, строки выше и ниже.
- `source`: `"vscode"`.

Мост один для браузера (Yandex.Code) и для VS Code: последний отправленный источник перезаписывает предыдущий.
