# HH.ru — пользовательский скрипт для SyntaxSurge

Userscript для отправки позиции курсора из редактора кода на hh.ru в мост SyntaxSurge.

## Установка

1. Установите расширение для userscripts: **Tampermonkey** или **Violentmonkey**
2. Создайте новый скрипт и вставьте содержимое `userscript_hh_ru.user.js`
3. Сохраните скрипт

## Поддерживаемые страницы

- **hh.ru** — основной сайт
- **career.hh.ru** — карьерный портал
- **assessment.hh.ru** — платформа тестирования (задачи по SQL, Python и др.)
- **skills.hh.ru** — подтверждение навыков
- Подстраницы hh.ru (тесты, задачи по программированию)

## Поддерживаемые редакторы

Скрипт подключается к **Monaco Editor** (assessment.hh.ru, тесты по SQL, Python, JavaScript).

## Использование

1. Запустите SyntaxSurge (gui_typer или main_window)
2. Откройте страницу с задачей по программированию на hh.ru
3. Кликните в редактор кода, чтобы фокус был на нём
4. Запустите печать — позиция курсора будет передаваться в мост

## Проверка

В консоли браузера (F12) должно появиться сообщение:
`[HH.ru→мост] Подключён Monaco Editor.` (или Ace / CodeMirror)

При движении курсора позиция отправляется на `http://127.0.0.1:8765/cursor`.
