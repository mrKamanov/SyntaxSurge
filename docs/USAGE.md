# Руководство пользователя SyntaxSurge

## Запуск приложения

| Режим | Команда | Описание |
|-------|---------|----------|
| Главное окно | `python run_gui.py` | Полный функционал: AI, скриншоты, печать, помощник |
| Облегчённый | `python gui_typer.py` | Только печать кода из выбранного файла |
| Консоль | `python run.py <файл>` | Печать без GUI |

---

## Главное окно

### Вкладки

- **Ответ** — текст ответа ИИ (с подсветкой Python, SQL, Markdown)
- **Подсказки** — построчные подсказки по коду (появляются при печати)
- **Ревью** — результат код-ревью (кнопка «Получить ревью»)

### Основные действия

1. **Получить ответ** — введите запрос и нажмите «Отправить» или используйте горячую клавишу
2. **Печать** — нажмите «Печать» или горячую клавишу; за 5 секунд переключитесь в редактор
3. **Скриншот** — захват экрана → OCR → AI → код в ответе
4. **Помощник** — голосовой ввод + диалог → краткие ответы

### Индикатор «Куда пойдёт печать»

В боковой панели отображается активное окно:
- **Печать → VS Code / Cursor** — при установленном расширении
- **Печать → PyCharm** — при установленном плагине
- **Печать → Браузер (HH.ru)** — при открытом hh.ru с userscript
- **Печать → Браузер (Yandex.Code)** — для Yandex.Code
- **Печать → Блокнот / редактор** — для остальных окон

### Подсказки при печати

При запуске печати код отправляется в API для анализа. Подсказки показываются:
- во вкладке «Подсказки»
- во всплывающем окне при печати (по текущей строке)

Подсказки **кэшируются** — при повторной печати того же ответа запрос в API не повторяется.

## Облегчённый интерфейс (gui_typer)

1. **Выберите файл** — кнопка «Выбрать…»
2. **Настройте** скорость и задержку перед стартом
3. **Нажмите СТАРТ** — за время задержки переключитесь в редактор
4. Печать начнётся автоматически

Отображаются: позиция курсора из моста, текущая строка, строки выше/ниже.

---

## Консольный режим
```bash
python run.py tests/1.py
```

1. Создаётся карта кода
2. Обратный отсчёт 5 секунд — переключитесь в редактор
3. Печать по карте

---

## Горячие клавиши

Настраиваются в **Настройки → Горячие клавиши**:
- Получить ответ
- Печать
- Пауза
- Скриншот
- И другие

**Или мышь:** средняя кнопка, боковые 1/2 + модификатор (Ctrl, Alt, Shift).

---

## Очистка карт

При каждом запуске приложения в папке `typer/map/` оставляются только **5 последних** карт по дате изменения. Остальные удаляются автоматически.
